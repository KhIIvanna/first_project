# 🚚 Система управління транспортною компанією

Повнофункціональний веб-додаток для управління замовленнями, клієнтами, водіями, транспортом та маршрутами транспортної компанії.

## ✨ Функціональність

### 📊 Головна панель
- Статистика в реальному часі (всього замовлень, нові, в дорозі, доставлено)
- Перегляд останніх замовлень
- Фільтрація замовлень за статусом
- Швидке оновлення статусу замовлень

### 📦 Управління замовленнями
- Створення нових замовлень
- Відстеження статусу доставки
- Видалення замовлень
- Детальна інформація про кожне замовлення

### 👥 Управління клієнтами
- Додавання нових клієнтів
- Перегляд кількості замовлень кожного клієнта
- Видалення клієнтів (якщо немає активних замовлень)

### 🚗 Управління транспортом
- Реєстрація транспортних засобів
- Прив'язка до водіїв
- Інформація про вантажопідйомність

### 👨‍✈️ Управління водіями
- Додавання водіїв
- Номери посвідчень
- Перегляд прив'язаних транспортних засобів

### 🗺️ Управління маршрутами
- Створення нових маршрутів
- Вказання відстані між точками
- Статистика використання маршрутів

### 🔍 Пошук
- Швидкий пошук по замовленнях
- Фільтрація за статусом
- Пошук за клієнтом, авто, маршрутом

## 🛠️ Технології

- **Backend**: Flask (Python)
- **Database**: MySQL
- **Frontend**: HTML5, CSS3, JavaScript
- **Іконки**: Font Awesome 6
- **Адаптивний дизайн**: Mobile-friendly

## 📋 Вимоги

- Python 3.7+
- MySQL 5.7+ або MariaDB 10.2+
- pip (менеджер пакетів Python)

## 🚀 Встановлення

### 1. Клонування репозиторію

```bash
cd transport_app
```

### 2. Створення віртуального середовища (рекомендовано)

```bash
python -m venv venv

# Активація на Windows:
venv\Scripts\activate

# Активація на Linux/Mac:
source venv/bin/activate
```

### 3. Встановлення залежностей

```bash
pip install flask mysql-connector-python
```

### 4. Налаштування бази даних

#### Створення бази даних

Запустіть MySQL клієнт і виконайте:

```sql
CREATE DATABASE transport_company CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

#### Створення таблиць

Виконайте SQL код з файлу початкової бази даних (скопіюйте створення таблиць з опису вище).

#### Додавання тестових даних

Виконайте SQL з файлу `test_data.sql` для додавання прикладних даних.

### 5. Налаштування підключення

Відредагуйте файл `app.py`, змінивши параметри підключення до MySQL:

```python
db_config = {
    "host": "localhost",
    "user": "ваш_користувач",      # Змініть на свого користувача MySQL
    "password": "ваш_пароль",       # Змініть на свій пароль
    "database": "transport_company"
}
```

### 6. Запуск додатку

```bash
python app.py
```

Додаток буде доступний за адресою: `http://localhost:5000`

## 🐛 Усунення проблем

### Помилка підключення до БД

```
Error: Access denied for user 'root'@'localhost'
```

**Рішення**: Перевірте правильність логіну та паролю у файлі `app.py`

### Помилка кодування

```
Error: Incorrect string value
```

**Рішення**: Переконайтесь, що БД створена з charset utf8mb4:

```sql
ALTER DATABASE transport_company CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### Порт вже зайнятий

```
Error: Address already in use
```

**Рішення**: Змініть порт у файлі `app.py`:

```python
app.run(debug=True, port=5001)  # Замість 5000
```
