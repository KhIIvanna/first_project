# Система управління транспортною компанією

Повнофункціональний веб-додаток для управління замовленнями, клієнтами, водіями, транспортом та маршрутами транспортної компанії.

---

## 📊 Функціональність

- **Головна панель**: статистика замовлень у реальному часі, останні замовлення, швидке оновлення статусів.
- **Замовлення**: створення, відстеження, видалення, детальна інформація.
- **Клієнти**: додавання, перегляд кількості замовлень, видалення.
- **Транспорт**: реєстрація авто, прив’язка до водіїв, вантажопідйомність.
- **Водії**: додавання, номери посвідчень, перегляд прив’язаних авто.
- **Маршрути**: створення, відстань між точками, статистика використання.
- **Пошук**: швидкий пошук по замовленнях, фільтрація за статусом, пошук за клієнтом/авто/маршрутом.

---

## 🛠️ Технології

- **Backend**: Flask (Python)
- **Database**: PostgreSQL (Neon)
- **Frontend**: HTML5, CSS3, JavaScript
- **Іконки**: Font Awesome 6
- **Хостинг**: Render
- **Адаптивність**: Mobile-friendly

---
